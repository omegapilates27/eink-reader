Thư viện & Kho Sách E-Ink

Đang xử lý tệp PDF & ghép dấu tiếng Việt... 0%

Hướng dẫn tải sách EPUB miễn phí về iPhone:

1. Mở thư viện sách

Chạm nút Mở kho sách ở bất kỳ nguồn nào bên dưới để tìm tựa sách yêu thích.

2. Tải tệp .EPUB

Chọn tải định dạng .EPUB → Tải về (Download) vào ứng dụng Tệp (Files).

3. Mở đọc E-Ink

Quay lại tab Sách của tôi → nhấn Mở tệp EPUB / PDF và chọn tệp vừa tải.

Lọc nguồn:

1. Lưu ứng dụng ra Màn hình chính iPhone

  1. Mở địa chỉ trang web GitHub Pages của bạn bằng trình duyệt Safari trên iPhone.
  2. Chạm vào biểu tượng Chia sẻ (Share) (ô vuông có mũi tên hướng lên ở cạnh dưới màn hình).
  3. Cuộn xuống và chọn Thêm vào MH chính (Add to Home Screen) → nhấn Thêm (Add).
  4. Mở ứng dụng từ màn hình chính để đọc toàn màn hình không thanh địa chỉ.

2. Tải tệp index.html hoàn chỉnh để up lên GitHub Pages

Nhấn nút bên dưới để tải trực tiếp tệp index.html đầy đủ của phiên bản này về iPhone, sau đó tải lên kho chứa GitHub của bạn (chọn Add file → Upload files → Commit changes).
