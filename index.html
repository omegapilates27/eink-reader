Cách tải sách EPUB về iPhone không bị lỗi:
1. Mở trang web bằng trình duyệt Safari gốc trên iPhone.
2. Chọn sách muốn đọc → bấm tải tệp định dạng .EPUB → chọn Tải về (Download) vào ứng dụng Tệp (Files).
3. Quay lại tab Sách của tôi → nhấn Mở tệp EPUB / PDF và chọn tệp vừa tải.
1. Lưu ứng dụng ra Màn hình chính iPhone
  1. Mở địa chỉ trang GitHub Pages của bạn bằng trình duyệt Safari trên iPhone.
  2. Chạm biểu tượng Chia sẻ (Share) (ô vuông có mũi tên hướng lên ở cạnh dưới màn hình).
  3. Chọn Thêm vào MH chính (Add to Home Screen) → nhấn Thêm (Add).
2. Tải tệp index.html hoàn chỉnh để up lên GitHub

Nhấn nút bên dưới để tải tệp index.html đầy đủ của phiên bản này về iPhone, sau đó tải lên kho chứa GitHub của bạn (Add file → Upload files → Commit changes).
